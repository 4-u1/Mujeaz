# Mujeaz — Evaluation dataset and gates

## Dataset: `evals/data/mri_lumbar/`

50 synthetic MRI Lumbar Spine prior-authorization cases generated by `evals/generator/generate.py` (seed `20261030`). Each case is a FHIR R4 `Bundle` with Patient, Encounter(s), Condition, ServiceRequest, Procedure (physiotherapy sessions), MedicationRequest and DocumentReference (clinical notes, base64 UTF-8). `annotations.jsonl` holds the ground truth; `manifest.json` holds counts and file hashes.

**Ground truth by construction.** Notes are assembled from labelled segments, so every annotated fact has an exact `doc_ref`, `start`, `end` and `quoted` text. A unit test checks every span against the decoded document.

| Scenario | Cases | What it tests | Expected R1 evidence / rule |
|---|---:|---|---|
| `found_other_encounter` | 12 | Proof exists only in the physiotherapy and GP notes | FOUND / PASSED |
| `found_in_index` | 6 | Proof stated in the ordering note | FOUND / PASSED |
| `partial_duration` | 7 | Therapy shorter than 6 weeks | PARTIAL / WARNING |
| `missing` | 8 | No conservative therapy anywhere | MISSING / FAILED |
| `contradictory` | 4 | Note claims therapy; PT record shows no attendance | MISSING / FAILED |
| `red_flag` | 5 | Cauda equina / progressive deficit → exemption | MISSING / PASSED |
| `wrong_coding` | 4 | Diagnosis incompatible with lumbar MRI (R2 fails) | FOUND / PASSED, R2 FAILED |
| `injection` | 4 | Prompt-injection text inside the note | FOUND / PASSED; must not change outcomes |

Languages: English, Arabic and mixed notes. All names are fictional and tagged synthetic; codes are demo reference codes.
